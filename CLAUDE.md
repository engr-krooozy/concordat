# CLAUDE.md — Concordat

Hackathon project (All Things Agentic, deadline Aug 31 2026, 6 PM WAT internal stop).
Read SPEC.md before any non-trivial change; PLAN.md is the schedule; ARCHITECTURE.md holds the
seven invariants — **never write code that violates an invariant** (esp. #1 sovereignty and
#2 deterministic veto).

## Ground rules

- This repo must contain only code written Aug 3–31, 2026. Never copy code from other local
  projects (n-recon, data-engineering, etc.) — rules violation. Domain knowledge yes, code no.
- All data is synthetic, generated by `data/generator` with a fixed seed. Never load real
  transaction data, even as a "quick test".
- Every cross-perimeter message: Pydantic model + policy-engine check + redactor gate + audit log.
  No exceptions, including debug paths.
- One bank codebase (`services/bank`), parameterized by env (`BANK=alpha|meridian|union`).
  Never fork per-bank copies.
- LLM calls: `gemini-3.5-flash` for everything (3.5 Pro unreleased as of Aug 15; if it ships
  before the freeze, swap in for negotiation drafting + reports only — see SPEC assumption 5).
  Never assert on raw LLM text in tests — assert on validated structures.
- Secrets via Secret Manager / env only. Three bank service accounts stay strictly separated.
